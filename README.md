# Abhi Pilli | Portfolio

A responsive, single-page portfolio for Abhi Pilli, highlighting his background in AI/ML, full-stack development, and IoT. The page includes skills, achievements, featured projects, a resume, and contact links with a form that opens a pre-filled WhatsApp message.

## Run Locally

No build tools or package installation are required. Open `index.html` in a web browser, or use the Live Server extension in VS Code.

The page loads Font Awesome icons from a CDN, so an internet connection is needed for those icons to appear.

## Project Files

- `index.html` - Page content and WhatsApp contact form behavior.
- `style.css` - Layout, colors, responsive styles, and visual presentation.
- `profile.png` - Profile image in the hero section.
- `official.png` - Profile image in the contact section.
- `bneuron.jpeg` - Achievement banner.
- `resume.pdf` - Resume shown and downloaded from the resume section.

Keep these asset files in the same folder as `index.html`; the page references them using relative paths.

## Updating Contact Details

The email address and phone number appear in the contact links and the WhatsApp form script in `index.html`. Update each occurrence together if those details change.
